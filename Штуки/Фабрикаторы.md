Для создания любого предмета из материала используются фабрикаторы. Разные компании создают свои фабрикаторы с различными функциями, программами и характеристиками приспособленными для какого-то особого класса предметов.

Кроме ценовой политики они различаются по скорости работы, затратам энергии, материалу и качеству работы.

Примеры:

«Скарабей»
Быстрый
Плохое качество 
Мало энергии
Любое качество материалов
Не может в сложные чертежи

«Муромасса»
Медленный
Хорошее качество
Много энергии
Хороший материал
Приспособлен под печать холодного оружия в любых проявлениях

«Полковник Кольт»
Средняя скорость
Хорошее качество
Среднее энергии
Хороший материал
Приспособлен для огнестрельного орудия

«Гаус-Тесла»
Медленный
Среднее качество
Много энергии
Средний материал
Приспособлен для создания энергетического оружия 

«Химера»
Средняя скорость
Среднее качество
Мало энергии
Любой материал
Просто огромен и может печатать большие объекты
